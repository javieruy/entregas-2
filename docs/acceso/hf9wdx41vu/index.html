מאיפה מתחילים?

  1. פתחו את הספר הראשי, בחרו יצירה מתוך 100 היצירות והדפיסו את הדף על נייר A4, בגודל מקורי.
  2. הסתכלו על הציור המקורי, קראו את העובדות המעניינות וצבעו את הדף לפי מקרא הצבעים.
  3. אחר כך עברו לתוכנית של 7 הימים בבונוס "צעדים ראשונים" ול־30 המשימות בבונוס "ציד פרטים".
  4. כשיש לכם כמה ציורים מוכנים, ארגנו תערוכה בעזרת הערכה "התערוכה הראשונה שלי".
